# J02 - Day·조사 Token·Save·단서·최종 추리 UI 구현

## 선행 Part
- 없음

## 구현 계획

1. 게임 상태 표시
   - Day, 역할, 조사 Token, 게임 내 시간 표시

2. 조사 Token 차감·소진 처리
   - 질문할 때 Token 차감, 모두 쓰면 질문 입력 막기

3. Save 슬롯 UI 구현
   - 저장 슬롯 3칸, 이어하기·새 수사, 채워진 슬롯 덮어쓰기 재확인
   - 슬롯마다 역할 고정

4. 단서 UI 구현
   - 단서 수첩, 단서 획득 알림
   - 기록 보관함에서 역할 등급보다 높은 파일은 잠금 표시

5. Day 전환 UI 구현
   - 다음 Day로 넘어가는 화면과 Token 초기화 표시

6. 최종 추리(지목) UI 구현
   - YB 지목·제출, 결과 화면

7. 서버 상태 연동 준비
   - Day·Token·Save·단서 값을 한곳에서 받도록 정리
   - 실제 API 연결은 J03에서 진행

8. 테스트
   - Token 차감·소진, Save 선택·덮어쓰기, 단서 획득, 지목 제출 흐름 확인
